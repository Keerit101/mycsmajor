Discrete math and logic · Chapter 2

Sets, properly

Most lost marks on sets come from notation rather than ideas. This chapter is about getting the notation exactly right, because the ideas are not hard.

What a set is

A set is an unordered collection of distinct things, called its elements. Two sets are equal when they have exactly the same elements, so:

{1, 2, 3} = {3, 2, 1} = {1, 2, 2, 3}

Order carries no information and repeats carry no information. Python agrees: {1, 2, 2, 3} == {3, 2, 1} is True.

Two ways to write a set down:

  • Roster: list the elements. A = {2, 4, 6, 8}.
  • Set-builder: state the rule. A = {x ∈ ℤ : x is even and 0 < x < 10}, read as "the set of integers x such that...". The colon (or a vertical bar) means "such that".

Names you are expected to know: ℕ the natural numbers, ℤ the integers, ℚ the rationals, ℝ the reals, and ∅ or {} the empty set.

Element or subset? The mistake worth fixing now

Two different relations, two different symbols:

  • ∈ is for elements. 2 ∈ {1, 2, 3}. The left side is a thing.
  • ⊆ is for subsets. {2} ⊆ {1, 2, 3}. The left side is a set.

So 2 ⊆ {1, 2, 3} is wrong, and {2} ∈ {1, 2, 3} is also wrong (the set {2} is not one of the three elements). Writing the wrong symbol costs marks even when the reasoning is right, so check every one.

It gets interesting when sets contain sets. For A = {1, {2, 3}}, A has exactly two elements: the number 1 and the set {2, 3}. So {2, 3} ∈ A is true, while 2 ∈ A is false and {1} ⊆ A is true.

Subset, proper subset, equality

A ⊆ B means every element of A is in B. A set is a subset of itself, and ∅ is a subset of every set. A ⊂ B (proper subset) means A ⊆ B and A ≠ B.

This gives the standard way to prove two sets are equal: show A ⊆ B and B ⊆ A. Chapter 4 does that properly; for now, note that it is the set version of proving a biconditional in two directions.

Operations

With A = {1, 2, 3, 4}, B = {3, 4, 5} and a universal set U = {1, ..., 6}:

OperationMeaningResultPython
A ∪ Bin A or in B{1,2,3,4,5}A | B
A ∩ Bin both{3,4}A & B
A − Bin A but not B{1,2}A - B
A ∆ Bin exactly one{1,2,5}A ^ B
A̅ (complement)in U but not A{5,6}U - A

A complement only means something once the universal set is stated. "Everything that is not in A" is not a set until you say what "everything" is.

Sets are disjoint when A ∩ B = ∅. The cardinality |A| is the number of elements, so |{1, 2, 3}| = 3 and |∅| = 0.

The same laws as logic

Set operations obey the laws from chapter 1, with ∪ for ∨, ∩ for ∧ and complement for ¬. That is not a coincidence: x ∈ A ∪ B is defined as (x ∈ A) ∨ (x ∈ B), so every set identity is a logical identity about membership.

De Morgan:      (A ∪ B)̅ = A̅ ∩ B̅        (A ∩ B)̅ = A̅ ∪ B̅
Distributive:   A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
Identity:       A ∪ ∅ = A              A ∩ U = A
Domination:     A ∪ U = U              A ∩ ∅ = ∅
Idempotent:     A ∪ A = A              A ∩ A = A
Absorption:     A ∪ (A ∩ B) = A

When your course asks for an identity proof "from LHS to RHS", this is the toolkit: rewrite one side step by step, naming the law each time, until it reads as the other side. No truth table, no elements, just the laws.

Power sets

The power set ℘(A) is the set of all subsets of A, including ∅ and A itself.

A = {1, 2}
℘(A) = { ∅, {1}, {2}, {1, 2} }

If |A| = n then |℘(A)| = 2ⁿ, because each element is either in a given subset or not: n independent two-way choices. That is the same 2ⁿ as the rows of a truth table, for exactly the same reason.

Two traps. ℘(∅) = {∅}, a set with one element, so its cardinality is 1 and not 0. And the elements of a power set are sets, so you write {1} ∈ ℘(A), with ∈, not ⊆.

Cartesian products

A × B is the set of ordered pairs (a, b) with a ∈ A and b ∈ B. Here order does matter, and |A × B| = |A| × |B|.

{1, 2} × {x, y} = { (1,x), (1,y), (2,x), (2,y) }

Products are how relations and functions are defined in chapter 7, and how database joins work in practice.

Checking yourself in Python

Python's sets use the same operations, which makes them a fast way to check an answer:

A = {1, 2, 3, 4}
B = {3, 4, 5}
U = set(range(1, 7))

print(A | B)                    # {1, 2, 3, 4, 5}
print(A & B)                    # {3, 4}
print(A - B)                    # {1, 2}
print(A ^ B)                    # {1, 2, 5}
print((U - (A | B)) == ((U - A) & (U - B)))   # True: De Morgan

Checking an identity on one example does not prove it, and a marker will not accept it. It does catch a misread question in ten seconds, which is worth a lot in revision.

Exercises

1. True or false

Let A = {1, 2, {3}}. Decide each: (a) 3 ∈ A; (b) {3} ∈ A; (c) {3} ⊆ A; (d) {{3}} ⊆ A; (e) ∅ ⊆ A; (f) |A| = 4.

Show answer

(a) False. The element is {3}, not 3.

(b) True. {3} is literally one of the three elements.

(c) False. {3} ⊆ A would need 3 ∈ A, and it is not.

(d) True. The only element of {{3}} is {3}, which is in A.

(e) True. The empty set is a subset of every set, vacuously: there is no element of ∅ that could fail to be in A.

(f) False. |A| = 3. A nested set counts as one element.

2. Prove an identity

Show that A − (B ∪ C) = (A − B) ∩ (A − C), working from the left side with named laws.

Show answer 
A − (B ∪ C)
= A ∩ (B ∪ C)̅              definition of difference
= A ∩ (B̅ ∩ C̅)             De Morgan
= (A ∩ A) ∩ (B̅ ∩ C̅)      idempotent, to get a second copy of A
= (A ∩ B̅) ∩ (A ∩ C̅)      commutative and associative
= (A − B) ∩ (A − C)         definition of difference

The step that looks like a trick is using A = A ∩ A to produce the second A. It is a standard move whenever the right-hand side mentions a set more often than the left-hand side does.

3. Counting with sets

In a class of 30, 18 take Python, 15 take Java and 7 take both. How many take neither? Then write the general rule you used.

Show answer

By inclusion-exclusion, |P ∪ J| = |P| + |J| − |P ∩ J| = 18 + 15 − 7 = 26. So 30 − 26 = 4 take neither.

Subtracting the intersection is the whole point: the 7 students taking both were counted twice, once in each total. The rule generalises to three sets as |A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|, which chapter 8 derives and uses.
