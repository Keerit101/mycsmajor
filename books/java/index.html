Java after Python

The language your second programming course is taught in.

Written for students who already know a little Python. Each chapter shows the Python you know, then the Java that does the same thing, and explains why Java asks for more.

Written alongside CPS 209. 12 chapters. 2 of them are free to read on this site, starting with:

  • Your first Java program: Install a JDK, compile and run, and understand why Java needs a class to print one line.
  • Types, and why Java insists: Primitives, objects, casting and the errors the compiler catches for you.
